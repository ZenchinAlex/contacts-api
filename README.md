# contacts-api

Контакты хранятся в базе данных SQLite (`contacts.db`).

## Возможности

| Запрос | Что делает | Коды ответа |
|---|---|---|
| `GET /contacts` | Вернуть все контакты | 200 |
| `GET /contacts/{name}` | Найти телефоны по имени | 200, 404 (контакт не найден) |
| `POST /contacts` | Добавить контакт (`name`, `phone`) | 200, 409 (такой контакт уже есть), 422 (неверные данные) |

## Как запустить

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
fastapi dev main.py
```

Сервер откроется на http://127.0.0.1:8000, документация и проверка запросов: http://127.0.0.1:8000/docs

Файл базы `contacts.db` и таблица `contacts` создаются автоматически при первом запуске.

## Чему я научился

- Подключил SQLite к FastAPI вместо JSON-файла: создал таблицу `contacts`, добавление (`INSERT`), поиск (`SELECT ... WHERE`) и проверка дубликатов теперь идут через SQL-запросы.
- Проверил, что данные сохраняются: остановил и перезапустил сервер, контакт остался в базе. Все запросы проверял через `/docs`.
